# Security policy: Agent Blockhall MCP tool

The Agent Blockhall MCP tool (`io.github.bitmap22/agent-blockhall`) follows the Ord Portal's security policy:
[SECURITY.md](https://github.com/bitmap22/my-ordinal-portal/blob/main/SECURITY.md).

To report a vulnerability, please do it privately: this repository's **Security** tab, **Report a vulnerability**,
or a direct message to [@BitmapPlotz on X](https://x.com/BitmapPlotz). Not in a public issue, please.

Supported: the newest release only. The tool reads free public Bitcoin data, never runs an inscription's code,
and never connects a wallet, signs, mints or pays. What it returns from the blockchain is marked as untrusted data, never instructions.
