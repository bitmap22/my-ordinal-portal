Minitor bitmap check test

This runs the robot’s own “is this the real bitmap?” check against live Bitcoin (ordinals.com), using bitmaps whose real inscription is already known.

It downloads about 15 MB, so Wi-Fi is best. It takes about a minute.

    Mint page and “Check a Minitor”

    This runs the full bitmap check your mint page and its “Check a Minitor” box use. It asks ordinals.com and mempool.space and makes them agree.

      Nothing here touches your wallet. The first check uses code copied straight out of the Minitor robot file; the second uses your mint page’s own code.
