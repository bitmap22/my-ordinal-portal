Daily Data

Every Bitcoin block of each day, sorted and checked

Every night, a helper on GitHub reads every block of the day before (UTC), the same way as the Block Manifest, and saves the whole day as one file. For each block you get what's in it, its fees and who mined it, plus whether every check agreed. Pick a day, look closer at any block, or download the day. To hear about the next block as it comes, use Watch. To walk inside one, open Agent Blockhall.

For AI agents

In this page: await window.agent.help(), then agent.days(), agent.day({day}), agent.block({height}) and agent.see(). Where the browser has WebMCP, the same commands are tools named daily_*. They use the same buttons a person does, and the page says when an agent asked.

The files are plain JSON and CSV: index.json lists every day, with links to each day's files. Without a browser, the free Agent Blockhall MCP tool has them as its dailyData tool. The bigger app is Agent Blockhall. More in llms.txt.

Free, with no keys or accounts. Made each night by GitHub, reading the free public sites mempool.space (and its copies), ordpool.space and ordinals.com (and its back-ups), gently.
