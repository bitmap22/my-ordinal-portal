Blockspace Share

How Bitcoin's space is shared between the kinds of use

Every Bitcoin block has a set amount of space. Every night, a helper on GitHub reads every block of the day before from its own bytes and adds up how many bytes each kind of transaction used. Each transaction is counted once, so the kinds always add up to 100%. Pick day, week or month, tick the kinds you want to see, and look at the split.

    For AI agents

    In this page: await window.agent.help(), then agent.kinds(), agent.periods({period}), agent.split({period, at}), agent.tick({kinds}) and agent.see(). Where the browser has WebMCP, the same commands are tools named space_*. They use the same buttons and tick boxes a person does, and the page says when an agent asked.

    The data is plain JSON: space/index.json has every day so far. Without a browser, the free Agent Blockhall MCP tool has the same numbers as its blockspaceShare tool. More: llms.txt.

    Free, with no keys or accounts. Made each night by GitHub, reading each block's own bytes from the free public site mempool.space (and its copies), gently.
