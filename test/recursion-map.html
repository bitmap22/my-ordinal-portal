Recursion Map

Everything a Bitcoin inscription loads from the chain, checked

Give an inscription's number or ID. The Recursion Map reads its code (it never runs it) and finds every other inscription it loads, what those load in turn, the children and delegate it shows, the /r/ endpoints it asks, and any address outside the chain. Then it checks each one still loads, on two ord sites. It's free, for people and AI agents. Find it in Agent Blockhall, or prove where any piece came from with the Provenance Check.

      The /r/ endpoints it asks

      Each one asked of ordinals.com today, with a test path.

        Outside the chain

        Addresses written in its code. They may be links, or things it loads: if they load, they can stop working one day.

          For AI agents

          In this page: await window.agent.help(), then agent.map({id, depth}), agent.node({id}) and agent.see(). Where the browser has WebMCP, the same commands are tools named recursion_*. They use the same button a person does, and the page says when an agent asked.

          The bigger app is Agent Blockhall. The Provenance Check proves where any one piece came from, and the Collection Check proves which pieces are a parent's real children.

          Without a browser: the free Agent Blockhall MCP tool has the same map as its recursionMap tool. The reader is one file, recursion.js, shared by this page and the tool. More in llms.txt.

          Free, with no keys or accounts. It reads free public sites: ordinals.com (and its back-ups), ord.xverse.app and ordiscan.com, gently: at most 30 asks at once, then 6 a second per site. It reads inscriptions' code to map it and never runs it; inscriptions belong to their creators: this page links to them and doesn't show them.
