Stuck Transaction Doctor

Is your Bitcoin transaction stuck? Why, and the fee that gets it in

Give it a transaction's ID. It says whether the transaction is stuck and why, then the fee that gets it in: by sending it again with a higher fee (replace it, "speed up"), or by spending one of its outputs in a new transaction that pays for both (a child pays for it). The fees come from real blocks: the same fee advice that keeps score of itself on Agent Blockhall's big screen. It only reads and works out: nothing is sent or signed. Free, for people and AI agents.

Fee advice only, not financial advice: it can be wrong, so check the fee in your own wallet before you send. A transaction can't be undone. Terms and disclaimer.

        For AI agents

        In this page: await window.agent.help(), then agent.check({txid}), agent.fees() (the fees aimed for now, each keeping score of itself) and agent.see(). Where the browser has WebMCP, the same commands are tools named stuck_*. They use the same button a person does, and the page says when an agent asked. Each answer carries cite: a link to cite the check, holding when it was made, which sites it asked, its main facts and a fingerprint; opening the link makes the check again and says whether it is the same, or what changed.

        The bigger app is Agent Blockhall: its big screen gives the same fee advice, and its kit can track a transaction. Once mined: the Block Manifest (its block), the Provenance Check (an inscription in it) and Watch (to be told when it goes in). How the sites are doing: Source Health.

        Without a browser: the free Agent Blockhall MCP tool has the same check as its stuckTx tool. The reader is one file, stuck.js, shared by this page and the tool. More in llms.txt.

        Free, with no keys or accounts. It reads free public sites: mempool.space (and its copies) and ordpool.space, gently. It only reads and works out: nothing is sent or signed, and only the wallet that made a transaction (or owns its output) can fix it. Nothing here is a promise: each fee is counted from the last day of blocks and the blocks waiting now.
